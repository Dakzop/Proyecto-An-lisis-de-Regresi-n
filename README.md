# Proyecto-Análisis-de-Regresión
Proyecto para el curso Análisis de Regresión UC-2026-1er Semestre

Pregunta de investigación: ¿Cuál es la combinación óptima de variables predictoras (antigüedad, distancia al transporte público, comercios cercanos y ubicación geográfica) que minimiza el error de predicción del precio de la vivienda al evaluar el modelo en datos no observados?
Link de descarga del dataset completo: https://archive.ics.uci.edu/dataset/477/real+estate+valuation+data+set
